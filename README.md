# Torque

A car article website for Irish drivers, built with Vue 3 and Vue Router.
Web Techniques project, Ilja Jascenkovs K00338854.

## How to run it

You need Node.js installed.

```bash
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Folders

- `src/data/` — the articles
- `src/components/` — reusable parts (header, footer, article card)
- `src/views/` — the pages (home, article)
- `src/router/` — which address shows which page
- `docs/` — planning and wireframes

## Done so far (Phase 1)
- Home page with article cards
- Article page for each article
- Navigation between pages with Vue Router
